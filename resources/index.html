PUBLIC API IMPORT

连接 GoComicMosaic

填写公开资源列表接口。页面会读取返回的标题、类型、简介、海报与链接，不会提交账号、Cookie 或密码。

接口需允许当前网页跨域读取（CORS）。若返回的是 HTML 首页，说明后端接口当前未开放或地址不正确。

GITHUB DATA

从 GitHub 导入公开数据

填写 raw JSON / CSV 地址或返回 JSON 的公开接口，也可以直接粘贴 GitHub 文件页链接。页面会读取片名、类型、简介、海报与链接；不会读取或提交账号、Cookie、密码。

支持 JSON 数组、CSV 表格，或包含 resources、items、data、list、results、movies 字段的 JSON 对象。接口需允许当前网页跨域读取（CORS）。

TVBOX SUBSCRIPTION

导入 TVBox 订阅

支持远程 JSON 地址、本地 JSON 文件或直接粘贴配置。可识别 sites、lives、parses、flags、headers 等字段；来源类型与地址原样保留。
